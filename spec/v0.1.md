# D-KaP Specification — v0.1 (Draft)

**Status:** Draft · **Editor:** EpochCore · **License:** Apache-2.0

## 1. Overview

D-KaP (Decentralized Knowledge as Pixels) defines a deterministic, content-addressed encoding of structured knowledge units as **pixel tensors** distributed across a 12-domain semantic fabric, anchored on dual-L2 commitment registries with post-quantum-safe cryptographic binding.

## 2. Goals

1. **Determinism** — the same knowledge unit always produces the same pixel tensor.
2. **Verifiability** — any consumer can prove a tensor's authenticity against the dual-chain anchor.
3. **Quantum safety** — binding primitives are PQC-safe (ML-KEM / ML-DSA family).
4. **Zero-latency lookup** — a single API surface returns address → tensor in O(1) amortized.

## 3. The 12 Domains

| # | Domain | Purpose |
|---|---|---|
| 1 | Identity | Subject / actor binding |
| 2 | Provenance | Origin & lineage |
| 3 | Temporal | Time anchors |
| 4 | Spatial | Geo / topology |
| 5 | Semantic | Concept embedding |
| 6 | Structural | Schema & shape |
| 7 | Evidence | Supporting artifacts |
| 8 | Attestation | Signatures & oracles |
| 9 | Policy | Access & usage rules |
| 10 | Economic | Value & settlement |
| 11 | Coverage | Risk & assurance |
| 12 | Bridge | Cross-fabric exports |

## 4. Pixel Tensor Encoding

A pixel tensor `T` for knowledge unit `K` is defined as:

```
T(K) = H_PQC( canonicalize(K) ) ⊕ domain_mask(K)
```

where `H_PQC` is a PQC-safe hash and `domain_mask` projects `K` onto the 12-domain basis.

## 5. Dual-Chain Anchor

Each pixel tensor commitment is anchored on **two independent L2s** to provide redundancy and prevent single-chain censorship. Anchor cadence: every `N` blocks (default `N = 64`).
